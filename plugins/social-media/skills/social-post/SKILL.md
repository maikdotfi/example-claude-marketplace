# Social post

Turn source material into posts that read like a person wrote them for that
specific platform — not one blurb pasted five times.

## 1. Establish the brief

You need four things. Take whatever the user already gave you and ask only for
what is genuinely missing and would change the copy:

- **Source material** — the release note, blog post, changelog, or raw idea. If
  they point at a file or URL, read it first.
- **Platforms** — which networks. If unstated, ask rather than guessing; posting
  to the wrong network is a real cost.
- **Goal** — the one action a reader should take: click, sign up, apply, reply,
  or simply understand a thing exists. One goal per post.
- **Voice** — if the user has existing posts, ask for one or two and match their
  register. Otherwise default to plain, concrete, first-person-plural.

## 2. Read the platform constraints

Read `references/platforms.md` before drafting. It carries the character limits,
truncation points, link behaviour, and hashtag conventions per network. Do not
work from memory on limits — a post that gets cut mid-sentence is a broken post.

## 3. Draft

For each requested platform, produce:

- **The post**, fully formed and ready to paste — no bracketed placeholders
  unless the user genuinely has to fill in a URL or date.
- **A character count**, and the limit it is measured against.
- **One alternative opening line**, so the user has a real choice on the hook.

Rules that hold across every platform:

- Front-load the substance. Every network truncates, and the first line is the
  only part guaranteed to be read.
- One idea per post. If the source has three, that is three posts or a thread.
- Name the specific thing. "40% faster cold starts" beats "improved performance".
- Write the CTA as a plain sentence, not a slogan.
- No engagement-bait openers ("Let that sink in.", "Unpopular opinion:"), no
  hashtag walls, no emoji as bullet points.
- Do not invent facts the source does not support — no numbers, quotes,
  customer names, or dates that are not in the material. If the post needs a
  metric to land and you do not have one, say so and leave it to the user.

## 4. Hand it over

Present each platform under its own heading so the user can copy one block at a
time. If a claim in the draft came from your inference rather than the source
material, flag it in one line underneath. Then offer to adapt the set for
another platform or push harder on a particular hook.
